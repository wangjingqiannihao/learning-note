# 好用的软件推荐

## Raycast

- 官网：
- 核心用途：快速启动应用、搜索文件、执行脚本和系统操作。
- 推荐理由：键盘驱动效率高，扩展生态丰富，适合把高频操作集中到一个入口。

## Beyond Compare

- 官网：
- 核心用途：对比文件、目录和代码差异，并支持合并修改。
- 推荐理由：差异展示清晰，目录同步能力强，处理配置、日志、代码对比很省时间。

## Snipaste

- 官网：
- 核心用途：截图、贴图、标注和临时固定参考内容。
- 推荐理由：轻量稳定，贴图功能实用，适合记录问题现场、对照信息和快速沟通。

## Multipass

- 官网：
- 核心用途：快速创建和管理 Ubuntu 虚拟机。
- 推荐理由：命令简单、启动快，适合本地搭建干净的 Linux 测试环境。
